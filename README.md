# NEST Client Gallery

Private editorial photo galleries for NEST clients.

## Product direction

- Editorial photography-first interface.
- Individual client access.
- Private photo storage and signed downloads.
- Responsive gallery with lightbox and collection download.

## Stack

- Next.js App Router
- TypeScript
- Supabase Auth, Postgres and private Storage
- Vercel deployment

The first implementation will include a public visual preview and the secure application foundation. Real client galleries require Supabase configuration and private media uploads.
